# Nova Client - mises à jour

Ce dépôt sert uniquement à distribuer les mises à jour de **Nova HUD**, le mod livré avec le
launcher **Nova Client** (Minecraft 1.9.4). Il ne contient aucun code source.

## Contenu des releases
- `novahud.jar` - le mod compilé
- `latest.json` - version, empreinte SHA-256 et notes, lues par le launcher

## Fonctionnement
Le launcher vérifie la dernière release au démarrage, puis toutes les 15 minutes. Quand une
nouvelle version est disponible, le bouton d'accueil propose **METTRE À JOUR** : le mod est
téléchargé, son empreinte vérifiée, puis installé au lancement suivant du jeu.

Rien à installer à la main : il suffit d'utiliser Nova Client.

## Le mod
Keystrokes et CPS, barre d'infos (FPS, ping, coordonnées, heure), équipement et durabilité,
effets de potions, santé et faim, munitions, boussole, horodatage du chat, fullbright, menu
principal personnalisé. Tout est réglable en jeu avec **Maj droite** : couleurs, taille,
position, fond.
